# Modelos de referencia Touch Plus

Fuente: Meta Quest Hardware Art, versión 1.8.
Página: https://developers.meta.com/vr/downloads/package/oculus-controller-art/
Descarga del archivo enlazado en esa página: 16/10/2026.

Se importaron únicamente los FBX izquierdo/derecho de Touch Plus, sus texturas de color y el archivo de atribución incluido. El archivo completo de descarga se conserva temporalmente en `Temp/T23/MetaArt/` y está excluido por `.gitignore`.

Uso: demostración visual del joystick y gatillo en T-23; no sustituye el sistema de entrada XRI ni instala Meta XR Core SDK.
Los materiales URP creados para el tutorial están en `Assets/_Project/Materials/Tutorial/`.

Se conserva `Oculus lineart attribution.txt` del paquete. Consultar las condiciones de uso desde la página oficial de descarga indicada arriba.

Las rotaciones demostrativas del tutorial se realizan sobre los huesos `*_b_thumbstick` y `*_b_trigger_front`; no son clips importados del SDK de Meta. Estado de animación y legibilidad en dispositivo: **SIN VERIFICAR**.
