# Iconos didácticos

Fuente: Lucide, https://lucide.dev/ y repositorio oficial https://github.com/lucide-icons/lucide.
Descargados el 16/10/2026: `move`, `rotate-ccw`, `mouse-pointer-click`, `pause`, `hand`.
Se conserva `LICENSE.txt` del repositorio.

Adaptación: trazos ámbar para contraste sobre el panel oscuro; PNG transparente de 256 px exportado desde los SVG con Inkscape. No se añade un paquete de código.

Los iconos acompañan instrucciones y demostraciones; no sustituyen por sí solos la enseñanza del control. Estado de comprensión y legibilidad en Quest: **SIN VERIFICAR**.
