PARTE 0 — SÍNTESIS DEL ALCANCE (extraída de
la tesis)
0.1 Lo que la tesis establece
 Aspecto            Qué dice la tesis

 Producto           Simulador de Realidad Virtual, prototipo, en Unity 6 LTS con URP y Meta
                    Quest 3 (Meta XR SDK)

 Población          Estudiantes de primer ciclo de TECSUP

 Propósito          Registrar decisiones y acciones del estudiante en situaciones académicas
                    simuladas y presentarlas en un reporte descriptivo como insumo
                    complementario para Psicopedagogía

 Lo que NO es       No diagnostica, no es evaluación clínica, no asigna puntajes ni niveles, no
                    mide competencias, no reemplaza al tutor
Competencias    Autorregulación emocional (Acto 1), adaptabilidad (Acto 2), trabajo en
priorizadas     equipo (Acto 3)

Estructura      Una experiencia de tres actos interactivos secuenciales, de duración
                prevista de 8 a 10 minutos (no medida)

Acto 1          Calificación baja y retroalimentación negativa del docente (profesor Miguel).
                Registro: reintentar la corrección o no actuar

Acto 2          Cambio inesperado de modalidad y grupo; notificación, compañero nuevo,
                objeto interactuable. Registro: plan nuevo, plan original o sin acción

Acto 3          Videollamada; desacuerdo entre compañeros e integrante que no cumple
                su tarea. Registro: opción A (mediar), B (apoyar), C (excluir) o D (pasivo)

Rutas           Ninguna ruta bloquea el avance; todos los actos se recorren de forma
                secuencial

Dentro de la    No se muestran puntajes ni mensajes de valoración
simulación

Variables       Reintento, OpcionAdaptabilidad, OpcionTrabajoEnEquipo y
registradas     metadatos de sesión (identificador seudonimizado, fecha, versión, estado
                de finalización)

Variables       Tiempos de respuesta, mirada, T_react (la clienta indicó que no aportan)
retiradas

Condición «no   Se determina por un tiempo de espera de diseño (parámetro técnico), no
actúa»          por una medición del tiempo de respuesta

Capas           Narrativa (Yarn Spinner 3.0) · Interacción (Meta XR SDK: objetos, zonas de
                proximidad, botones en espacio 3D) · Registro de decisiones
                (GameSessionData, Act Managers) · Reporte
                (ReporteManager.GuardarReporte())

Almacenamien    Archivo de texto estructurado (reporte.txt) en
to              Application.persistentDataPath

Reporte         Encabezado con código de sesión, fecha y versión · aviso de límites · por
                acto: situación, frase descriptiva predefinida y preguntas orientadoras ·
                calidad del registro. Lenguaje descriptivo, no interpretativo; frases escritas
                de antemano, sin inteligencia artificial

Fuera de        Diagnóstico, reemplazo de la tutoría, multijugador en línea, plataforma web,
alcance         IA para diagnóstico o predicción, compatibilidad con otras gafas, análisis
                longitudinal

Ética           Consentimiento informado previo (aún sin documentar), código de sesión
                sin nombre, acceso restringido, no uso académico ni disciplinario

E4 a E6 — Los tres actos
Cada acto sigue la misma secuencia [PROPUESTA TÉCNICA]:
    1.​ Transición de entrada (fundido a negro 1 s, tarjeta «Situación N de 3» 2,5 s, fundido de
        entrada 1 s).
    2.​ Presentación (instrucciones y diálogos de contexto).
    3.​ Evento disparador.
    4.​ Momento de decisión (opciones visibles, tiempo de espera cuando corresponde).
    5.​ Reacción de los personajes según la decisión.
    6.​ Cierre del acto y registro.

Visualización o exportación (alcance viable) [PROPUESTA TÉCNICA]. La tesis define que el
reporte se guarda como archivo de texto y que el tutor lo consulta al término de la sesión. No se
muestra dentro del visor (para no exponer los datos al estudiante). Para consultarlo: conectar el
visor por cable USB y copiar el archivo desde la carpeta de datos de la aplicación (con Meta

iniciar la aplicación (Debug.Log(Application.persistentDataPath)). Un visor integrado de
reportes y la exportación en PDF requerirían ampliar el alcance (ver §8.4).

PARTE 2 — GUION COMPLETO
Todo el contenido narrativo de esta parte es [PROPUESTA – VALIDAR CON CLIENTA]. Los
nombres de los personajes (excepto el profesor Miguel, que figura en la tesis), los diálogos, los

Interaction/RayPointer.cs
using System.Collections;
using UnityEngine;

namespace CrisisVR
{
    public class RayPointer : MonoBehaviour
    {
        public OVRInput.Controller controller = OVRInput.Controller.RTouch;
        public Transform origin;            // RightHandAnchor
        public LineRenderer line;
        public float maxDistance = 6f;
        public LayerMask mask;              // capa Interactable

        Selectable3D current;

        void Update()
        {
            var ray = new Ray(origin.position, origin.forward);
            Selectable3D hit = null; float d = maxDistance;
            if (Physics.Raycast(ray, out RaycastHit h, maxDistance, mask))
            {
                hit = h.collider.GetComponentInParent<Selectable3D>(); d =
h.distance;
            }
            if (hit != current)
            {
                if (current) current.SetHover(false);
                current = hit;
                if (current) current.SetHover(true);
            }
            line.SetPosition(0, origin.position);
            line.SetPosition(1, origin.position + origin.forward * d);

            if (current && current.Interactable &&
                OVRInput.GetDown(OVRInput.Button.PrimaryIndexTrigger, controller))
            {
                current.Select();
                StartCoroutine(Haptic());
            }
        }

        IEnumerator Haptic()
        {
            OVRInput.SetControllerVibration(0.5f, 0.3f, controller);
            yield return new WaitForSecondsRealtime(0.08f);
            OVRInput.SetControllerVibration(0f, 0f, controller);
        }
    }
}


Interaction/ChoicePrompt.cs
using System;
using System.Collections;
using System.Collections.Generic;

namespace CrisisVR
{
    public static class ChoicePrompt
    {
        // timeout <= 0: sin tiempo de espera. result(null) = no hubo selección.
        public static IEnumerator Ask(IList<Selectable3D> options, float timeout,
Action<string> result)
        {
            string chosen = null;
            void OnSel(Selectable3D s) { chosen = s.id; }

            foreach (var o in options) { o.gameObject.SetActive(true);
o.SetInteractable(true); o.Selected += OnSel; }

            float t = 0f;
            while (chosen == null)
            {
                if (!GameClock.Paused)
                {
                    t += UnityEngine.Time.deltaTime;
                    if (timeout > 0f && t >= timeout) break;
                }
                yield return null;
            }
            foreach (var o in options) { o.Selected -= OnSel;
o.SetInteractable(false); }
            result(chosen);
        }
    }
}

go.SetActive(state == "on"); }
        void Npc(string id, string state) { var n = registry.GetNpc(id); if (n)

using System.Text;

namespace CrisisVR
{
    public static class ReportBuilder
    {
        // Todos los textos son [PROPUESTA – VALIDAR CON CLIENTA].
        const string Aviso =
            "Este reporte describe decisiones y acciones del estudiante en una
simulación breve. " +
            "No constituye un diagnóstico ni una evaluación clínica, no asigna
niveles ni puntajes " +
            "y no reemplaza el criterio del profesional de Psicopedagogía.";

        const string OpA = "Propongo que cada uno diga qué parte puede entregar y
para cuándo, y armamos un plan juntos.";
        const string OpB = "Lucía, yo puedo ayudarte con la presentación para
avanzar más rápido.";
        const string OpC = "Mateo no ha avanzado nada; sigamos sin él y repartamos
su parte entre nosotros.";
        const string OpD = "Prefiero esperar a ver qué deciden ustedes.";

         public static string Build(SessionData s)
         {
             var b = new StringBuilder();
             b.AppendLine("CRISIS VR — REPORTE DESCRIPTIVO DE SESIÓN");
             b.AppendLine("Código de sesión: " + s.sessionId);
             b.AppendLine("Fecha y hora de inicio: " + s.startedAt);
             b.AppendLine("Versión de la aplicación: " + s.appVersion);
             b.AppendLine("Estado de la sesión: " + s.endReason);
             b.AppendLine();
             b.AppendLine("AVISO DE LÍMITES");
             b.AppendLine(Aviso);
             b.AppendLine();

            // Situación 1
            b.AppendLine("SITUACIÓN 1 — Retroalimentación negativa del docente");
            b.AppendLine("Situación diseñada en relación con: autorregulación
emocional (marco del proyecto; no se mide).");
            if (s.act1Registered)
            {
                b.AppendLine("Lo que ocurrió: el estudiante entregó su proyecto y
el docente le comunicó una calificación de 08 sobre 20 y la retroalimentación
correspondiente.");
                b.AppendLine("Decisión registrada: " + (s.Reintento
                    ? "tras recibir la retroalimentación, el estudiante seleccionó
la opción de corregir el proyecto."
                    : "tras recibir la retroalimentación, el estudiante no
seleccionó ninguna acción durante el tiempo disponible, y la sesión continuó."));
                b.AppendLine("Pregunta orientadora: ¿Qué pensabas mientras
escuchabas la retroalimentación del profesor?");
            }
            else b.AppendLine("Sin registro: la sesión terminó antes de esta
situación.");
            b.AppendLine();

            // Situación 2
            b.AppendLine("SITUACIÓN 2 — Aviso de cambio de modalidad y de grupo");
            b.AppendLine("Situación diseñada en relación con: adaptabilidad (marco
del proyecto; no se mide).");
            if (s.OpcionAdaptabilidad != Act2Result.SinRegistro)
            {
                b.AppendLine("Lo que ocurrió: llegó un aviso de cambio de la
práctica a modalidad virtual y de reorganización de los grupos; apareció un
compañero nuevo.");
                switch (s.OpcionAdaptabilidad)
                {
                    case Act2Result.PlanNuevo:    b.AppendLine("Decisión
registrada: ante el aviso, el estudiante seleccionó el plan nuevo (práctica
virtual)."); break;
                    case Act2Result.PlanOriginal: b.AppendLine("Decisión
registrada: ante el aviso, el estudiante seleccionó el plan original (práctica
presencial)."); break;
                    default:                      b.AppendLine("Decisión
registrada: ante el aviso, el estudiante no seleccionó ninguna opción durante el
tiempo disponible, y la sesión continuó."); break;
                }
                b.AppendLine("Pregunta orientadora: ¿Qué te llevó a elegir esa
opción (o a no elegir)?");
            }
            else b.AppendLine("Sin registro: la sesión terminó antes de esta
situación.");
            b.AppendLine();

            // Situación 3
            b.AppendLine("SITUACIÓN 3 — Reunión de equipo");
            b.AppendLine("Situación diseñada en relación con: trabajo en equipo
(marco del proyecto; no se mide).");
            if (s.OpcionTrabajoEnEquipo != Act3Result.SinRegistro)
            {
                b.AppendLine("Lo que ocurrió: en una videollamada, dos compañeros
discreparon sobre el reparto de tareas y un integrante informó que no tenía lista
su parte.");
                string txt = s.OpcionTrabajoEnEquipo == Act3Result.Mediar ? OpA :
                             s.OpcionTrabajoEnEquipo == Act3Result.Apoyar ? OpB :
                             s.OpcionTrabajoEnEquipo == Act3Result.Excluir ? OpC :
OpD;
                b.AppendLine("Decisión registrada: ante el conflicto en el equipo,
el estudiante eligió la opción: \"" + txt + "\"");
                b.AppendLine("Pregunta orientadora: ¿Qué pensaste mientras tus
compañeros discutían?");
            }
            else b.AppendLine("Sin registro: la sesión terminó antes de esta
situación.");
            b.AppendLine();

            b.AppendLine("CALIDAD DEL REGISTRO");
            b.AppendLine("Situación 1 completada: " + (s.act1Completed ? "sí" :
"no"));
            b.AppendLine("Situación 2 completada: " + (s.act2Completed ? "sí" :
"no"));
            b.AppendLine("Situación 3 completada: " + (s.act3Completed ? "sí" :
"no"));
            b.AppendLine("En las situaciones 1 y 2, la ausencia de selección se
determina porque vence un tiempo de espera definido en el diseño; no se mide el
tiempo de respuesta del estudiante.");
            b.AppendLine();
            b.AppendLine("LIMITACIONES DE INTERPRETACIÓN");
            b.AppendLine("Este reporte refleja una decisión por situación en una
simulación acotada. Una decisión puede obedecer a razones muy distintas. " +
                         "Solo cobra sentido dentro de la conversación del
profesional con el estudiante y junto con otras fuentes de información.");
            return b.ToString();
        }
    }

using System.IO;

namespace CrisisVR
{
    public static class ReportWriter
    {
        public static string Write(SessionData s)
        {
            string path = Path.Combine(Application.persistentDataPath,
$"CrisisVR_{s.sessionId}.txt");
            File.WriteAllText(path, ReportBuilder.Build(s), new
UTF8Encoding(false));
            Debug.Log("Reporte guardado en: " + path);
            return path;
        }
    }
